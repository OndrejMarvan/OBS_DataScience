# Recommended Obsidian Setup

## Essential Plugins (Install First)

### 1. Templater
- Enables the templates in `_templates/`
- Set template folder to `_templates`
- Configure hotkeys for quick note creation

### 2. Dataview
- Powers all dynamic queries in `_system/dataview-queries/`
- Enables live vocabulary counts and progress tracking

### 3. Spaced Repetition
- Looks for `#review` tags and `?` flashcard markers in notes
- Set review schedule (daily recommended)
- Works with the flashcard format already built into word-note template

### 4. Excalidraw or Canvas
- For visual mind maps connecting language concepts
- Great for grammar comparison diagrams
- Canvas is built-in; Excalidraw is community plugin with more features

### 5. Calendar
- Track daily study logs
- Visual overview of study consistency

## Optional but Helpful

### 6. Textfresser (for German)
- Auto-generates German word entries with conjugation/declension tables
- Pairs well with the word-note template

### 7. Languagetool
- Grammar/spell checking in multiple languages
- Helps when writing practice texts

### 8. Various Checkboxes / Kanban
- For tracking progress through curriculum units

## Vault Settings

### Appearance
- Use a clean theme (Minimal or Blue Topaz recommended)
- Enable "Readable line length" for comfortable reading
- Consider a bilingual-friendly font (e.g., Noto Sans, which supports Cyrillic)

### Files and Links
- Use `[[Wikilinks]]` (default) — essential for the linking system
- Enable "Automatically update internal links" when renaming notes

### Hotkeys (Suggested)
| Action | Suggested Hotkey |
|--------|-----------------|
| New note from word template | Ctrl+Shift+W |
| New daily log | Ctrl+Shift+D |
| Open graph view | Ctrl+G |
| Toggle spaced repetition | Ctrl+Shift+R |
| Search vault | Ctrl+Shift+F |

## Graph View Tips
- Color-code by tag: different colors for `#lang/pl`, `#lang/de`, `#lang/ru`
- Filter to see only one language's connections
- The graph naturally shows which concepts are most connected

## Mobile Setup
- Obsidian has iOS and Android apps
- Sync via Obsidian Sync, iCloud, or Git
- Great for reviewing flashcards on the go
