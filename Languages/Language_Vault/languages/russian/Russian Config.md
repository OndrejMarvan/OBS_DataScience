# 🇷🇺 Russian — Language Configuration

## Language Info
- **Language:** Russian (русский язык)
- **ISO Code:** ru
- **Language Family:** Indo-European → Slavic → East Slavic
- **Script:** Cyrillic (А Б В Г Д Е Ё Ж З И Й К Л М Н О П Р С Т У Ф Х Ц Ч Ш Щ Ъ Ы Ь Э Ю Я)
- **Current Level:** Beginner
- **Target Level:** B1+

## Relationship to Your Languages

| Compared to | Family Distance | Helpful For | Watch Out For |
|-------------|----------------|-------------|---------------|
| 🇨🇿 Czech | Moderate (West vs East Slavic) | Huge vocabulary overlap, case system, aspect, verb patterns | Cyrillic, mobile stress, different prepositions sometimes |
| 🇬🇧 English | Distant | International/academic vocabulary | Almost nothing structurally similar |
| 🇵🇱 Polish | Moderate-close | Even more vocabulary overlap than CZ-RU, similar grammar | Polish has 7 cases, Russian has 6 (no vocative). Stress patterns differ. |
| 🇩🇪 German | Distant | Very little | Almost everything differs |

## Key Features
- **Cases:** 6 (именительный, родительный, дательный, винительный, творительный, предложный) — no vocative!
- **Genders:** 3 (мужской, женский, средний)
- **Verb aspects:** Yes — совершенный (perfective) / несовершенный (imperfective) — same as CZ/PL!
- **Word order:** Free (SVO default) — same as Czech/Polish
- **Articles:** None — same as Czech/Polish

## Key Sound Correspondences CZ/PL → RU
1. CZ **h** → RU **г** (hora→гора, hlava→голова)
2. CZ/PL **ě/ie** → RU **e** (mleko→молоко, biały→белый)
3. CZ **ř** → RU **р** (řeka→река — Russian just has plain r)
4. PL **ą/ę** → RU no nasals (ząb→зуб, język→язык)
5. CZ/PL **-ost/-ość** → RU **-ость** (radost→радость, miłość→милость)

## Learning Priority
1. First focus: Cyrillic — reading and writing fluently (use the map above)
2. Then: Basic vocabulary using Czech/Polish cognates as anchors
3. Then: Mobile stress patterns (this is the hardest part — no fixed rule)
