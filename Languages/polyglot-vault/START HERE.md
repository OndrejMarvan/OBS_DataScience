# 🌍 Polyglot Vault — Multilingual Learning System

Welcome to your cross-linguistic learning vault. This system is built on the principle of **associative transfer** — using what you already know in one language to accelerate learning in others.

## How This Vault Works

### Core Principles
1. **One concept, many languages** — Each vocabulary note shows the word across all languages
2. **Pattern recognition** — Sound shifts, cognate families, and grammar parallels are explicitly mapped
3. **Associative linking** — Every note links to related concepts, grammar rules, and patterns
4. **Spaced repetition** — Notes are formatted for the Obsidian SR plugin

### Folder Structure
- `_templates/` — Note templates for every type (word, grammar, pattern, etc.)
- `_meta/` — Language configuration, tag taxonomy, progress tracking
- `_system/` — Dataview queries and dashboards
- `curriculum/` — Structured A1→C1 learning path (start with Polish, adapt for others)
- `vocabulary/` — Word notes organized by theme and frequency
- `grammar/` — Grammar rules with cross-linguistic comparisons
- `patterns/` — Sound shifts, cognate families, shared idioms
- `languages/` — Language-specific reference (alphabet, pronunciation, etc.)
- `resources/` — External links, book recommendations, media

### Recommended Plugins
- **Spaced Repetition** — Flashcard review from your notes
- **Dataview** — Dynamic queries to track vocabulary and progress
- **Excalidraw** or **Canvas** — Visual mind maps
- **Templater** — Use the templates in `_templates/`
- **Textfresser** — German vocabulary helper
- **Calendar** — Daily study tracking

### How to Add a New Language
1. Copy `_meta/language-config-template.md` → rename to your language
2. Create a subfolder in `languages/`
3. Start adding vocabulary using `_templates/word-note.md`
4. The cross-linguistic fields in the template will guide you

### Quick Start
1. Install recommended plugins
2. Open `curriculum/A1/A1 - Overview.md`
3. Start working through topics
4. Create vocabulary notes using the word template
5. Review with spaced repetition daily
