## How to Avoid False Friend Traps

1. **When you think "I know this word!"** — pause and verify
2. **Mark every false friend** with ⚠️ in your word notes
3. **Create mnemonics** for the worst ones:
   - CZ čerstvý = fresh → think "ČERstvý = ČERešně (cherries) are FRESH"
   - PL czerstwy = stale → think "CZERSTWY chleb is CRUSTY (stale)"
4. **Review false friends MORE frequently** in spaced repetition
5. **Context saves you** — even if you use the wrong word, context usually clarifies
