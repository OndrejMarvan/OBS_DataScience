# 🇵🇱 Path — Polish (B1 → C1)

**Your situation:** Conversational already. Czech gives you ~75% of core vocabulary for free. Your enemies are: false friends, spelling interference, penultimate stress, and a comfort-zone plateau ("I get by, so I stop improving").

**Your goal:** Not "learn Polish" — you basically know Polish. Your goal is **precision and range**: sounding Polish rather than like a Czech speaking Polish.

## Phase 1 — Fix the foundation cracks (2-4 weeks)
The mistakes you make now are fossilizing. Attack them directly:
1. Read [[Polish Pronunciation for Czech Speakers]] — drill the **penultimate stress** consciously for a week (this is the #1 Czech giveaway)
2. Read [[Polish Grammar for Czech Speakers]] — especially the **Pan/Pani 3rd-person system** and **masculine personal plural** (oni robili vs one robiły)
3. Memorize the top-20 rows of [[False Friends Master List]] — czerstwy, szukać, zachód, chyba. These cause real embarrassment.
4. Skim [[CZ ř - PL rz]] — it makes Polish *spelling* predictable from Czech

**Weekly rhythm:** 3× input (see below), 2× output, daily SR.

## Phase 2 — Range expansion (2-4 months)
- Input: **real Polish media at full speed.** News podcasts, Polish YouTube commentary, Netflix with Polish audio AND Polish subtitles. You're past graded content.
- The killer technique for you: **read a book in Polish that you've already read in Czech.** Zero dictionary needed, massive acquisition.
- Vault use: before consuming content on a topic, prime with the relevant file from [[Vocabulary Index by Theme]]. After, log 5 unknowns as word notes.
- Grammar targets: [[B1-B2 Prefixed Verb Families]] (map CZ prefixes → PL), [[B1 Reflexive Verbs Comparison]] (the się mismatches)

## Phase 3 — Precision (ongoing → C1)
- Focus files: [[B2-C1 Connectors and Discourse Markers]], [[B2 Essential Collocations]], [[Idioms Extended]] — this is what separates B1 "getting by" from C1 "sounding educated"
- Output escalation: write short texts (email, opinion paragraph) weekly; get corrections (tutor, tandem partner, or paste into a chat with me and ask for native-style correction)
- Register: practice switching Pan/Pani ↔ ty deliberately. Polish formality is stricter than Czech — under-formality reads as rude.

## Traps specific to you
| Trap | Fix |
|------|-----|
| First-syllable stress (Czech habit) | Exaggerate penultimate stress until it feels silly |
| Using CZ word with PL pronunciation and hoping | Check false friends first; when guessing, flag it mentally |
| Plateau: "everyone understands me" | That's B1 comfort. C1 = *they forget you're foreign*. Chase precision, not comprehension. |
| Writing ż where rz belongs | If the Czech cognate has ř → write rz. See [[CZ ř - PL rz]] |
