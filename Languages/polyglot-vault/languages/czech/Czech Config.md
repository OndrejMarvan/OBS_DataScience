# 🇨🇿 Czech — Language Configuration (Native Reference)

## Language Info
- **Language:** Czech (čeština)
- **ISO Code:** cs
- **Language Family:** Indo-European → Slavic → West Slavic → Czech-Slovak
- **Script:** Latin (with háčky a čárky: á, č, ď, é, ě, í, ň, ó, ř, š, ť, ú, ů, ý, ž)
- **Level:** Native (L1)
- **Role in vault:** Foundation — all other languages are compared to Czech

## Why Czech is Your Superpower
Czech is the anchor of your entire system. Here's what it gives you for free:

### → Polish
- ~80% vocabulary overlap (once you learn the spelling differences)
- Identical case system (7 cases)
- Same verb aspect system
- Same word order freedom
- Main work: spelling conventions, nasal vowels, stress shift

### → German
- Centuries of contact = hundreds of loanwords already in Czech
- Case system concept (4 vs 7, but the logic is the same)
- First-syllable stress (same as Czech!)
- Main work: articles, V2 word order, separable verbs

### → Russian
- ~60% vocabulary overlap (deeper roots)
- Same case logic (6 vs 7)
- Same aspect system
- Main work: Cyrillic, mobile stress, vocabulary that diverged

### → English
- English is your bridge to Germanic vocabulary
- Many international words came through English
- Main bridge: Latin/Greek academic vocabulary shared by all 5 languages
