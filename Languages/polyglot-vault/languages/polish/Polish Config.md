# 🇵🇱 Polish — Language Configuration

## Language Info
- **Language:** Polish (język polski)
- **ISO Code:** pl
- **Language Family:** Indo-European → Slavic → West Slavic → Lechitic
- **Script:** Latin (with diacritics: ą, ć, ę, ł, ń, ó, ś, ź, ż)
- **Current Level:** Conversational (~B1)
- **Target Level:** C1

## Relationship to Your Languages

| Compared to | Family Distance | Helpful For | Watch Out For |
|-------------|----------------|-------------|---------------|
| 🇨🇿 Czech | Very close (same branch) | Nearly everything — grammar, vocabulary, word formation | False friends (szukać≠šukat, ovoce≠owoce patterns), different diminutive endings |
| 🇬🇧 English | Distant (different branch) | International vocabulary, loanwords, word order in simple sentences | Grammar is completely different, English has no cases |
| 🇩🇪 German | Distant but historical contact | Many loanwords (ratusz, dach, rynek, handel), some structural parallels in case system | German has 4 cases not 7, V2 word order |
| 🇷🇺 Russian | Moderately close (East vs West Slavic) | Massive vocabulary overlap, aspect system, case logic | Different stress patterns, Cyrillic, some grammar differences (no vocative in RU) |

## Key Features
- **Cases:** 7 (mianownik, dopełniacz, celownik, biernik, narzędnik, miejscownik, wołacz)
- **Genders:** 3 (męski, żeński, nijaki) + masculine personal/non-personal plural distinction
- **Verb aspects:** Yes — dokonany (perfective) / niedokonany (imperfective)
- **Word order:** Free (SVO default), pragmatic ordering
- **Articles:** None (like Czech, Russian — unlike German, English)

## Pronunciation Key Points
- **Nasal vowels ą, ę** — don't exist in Czech! Before stops: ą→[om/on], ę→[em/en]. Word-final ę often just [e].
- **ł** = [w] (like English 'w') — CZ doesn't have this
- **sz, cz, ż/rz** = CZ š, č, ž (same sounds, different spelling!)
- **ś, ć, ź, ń** = soft consonants (palatalized) — similar to CZ ť, ď, ň but spelled differently
- **Stress:** Almost always on penultimate (předposlední) syllable — unlike Czech (first syllable)
- **h vs ch:** In Polish both exist but ch=[x] always, h=[x] too (merged). In Czech h=[ɦ], ch=[x].

## Top Cognate Patterns from Czech
1. CZ **ř** → PL **rz** (řeka→rzeka, dřevo→drzewo, třeba→trzeba)
2. CZ **ou** → PL **ó** [u] (moucha→mucha, louka→łąka, koupit→kupić)
3. CZ **-ý/-í** → PL **-y/-i** (dobrý→dobry, malý→mały)
4. CZ **v-** → PL **w-** (voda→woda, velký→wielki, výborný→wyborny)
5. CZ **h** → PL **g** in some words (noha→noga, hora→góra) — reflects Proto-Slavic *g

## Top False Friends from Czech ⚠️
1. CZ **čerstvý** (fresh) ≠ PL **czerstwy** (stale!) — OPPOSITE meaning!
2. CZ **ovoce** (fruit) ≠ PL **owoce** (fruit) — same here, but CZ **šukat** (to fuck) ≈ PL **szukać** (to search!)
3. CZ **hledět** (to look) ≠ PL **patrzeć** (to look) — different verbs
4. CZ **dívka** (girl) ≈ PL **dziewczyna** (girl) — different words
5. CZ **kapsa** (pocket) ≠ PL **kieszeń** (pocket) — different words
6. CZ **pozor** (attention!) ≈ PL **pozór** (pretense) — careful!
7. CZ **záchod** (toilet) ≈ PL **zachód** (west/sunset) — very different!

## Learning Priority
1. First focus: Fix the spelling differences (sz/cz/ż vs š/č/ž), master nasal vowels
2. Then: Vocabulary expansion using Czech as base + learning the divergent words
3. Then: Polish-specific grammar (masculine personal plural, different diminutive patterns)
