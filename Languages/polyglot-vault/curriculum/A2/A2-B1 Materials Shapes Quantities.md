> **Triangle:** CZ trojúhelník = PL trójkąt = DE Dreieck = RU треугольник — ALL mean "three-angle/corner"!
> **Rectangle:** CZ obdélník = PL prostokąt = DE Rechteck = RU прямоугольник — "long-part" / "right-angle" / "right-corner" / "straight-angle"
> **Gold:** CZ zlato = PL złoto = RU золото — identical root! One of the oldest shared Slavic words.
> **Iron:** CZ železo = PL żelazo = RU железо — identical root! CZ ž↔PL ż pattern.
> **Clay:** CZ hlína = PL glina = RU глина — CZ h↔PL/RU g pattern again!
