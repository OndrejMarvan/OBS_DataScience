> **Human rights:** CZ lidská práva = PL prawa człowieka = DE Menschenrechte = RU права человека — same compound in all: "human/person + rights"
> **Freedom of speech:** CZ svoboda slova = PL wolność słowa = RU свобода слова — nearly identical phrase! (CZ uses "projevu" more formally)
> **Trade union:** CZ odborový svaz = PL związek zawodowy = RU профсоюз (профессиональный союз). PL+RU both use "union" concept, CZ uses "svaz" (alliance).
> **Strike:** CZ stávka ≠ PL strajk = DE Streik = RU забастовка. PL borrowed from DE/EN. CZ and RU have native words.
> **Suburb:** CZ předměstí = PL przedmieście = RU пригород — CZ+PL identical compound! ("before-city")
