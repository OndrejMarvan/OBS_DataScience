> **Coal:** CZ uhlí = PL węgiel = RU уголь — CZ+RU cognate (uhlí/уголь from "uhel/угол"=corner/coal). PL węgiel from different root but also means "carbon."
> **Greenhouse effect:** CZ skleníkový efekt = PL efekt cieplarniany = DE Treibhauseffekt = RU парниковый эффект — CZ "glass-house", PL "warm-house", DE "drive-house", RU "steam-house." All different metaphors for the same concept!
> **Carbon footprint:** CZ uhlíková stopa = PL ślad węglowy = RU углеродный след = DE CO₂-Fußabdruck. CZ+PL+RU all use native words for "carbon trace/trail."
> **Waste sorting:** CZ třídění odpadu = PL segregacja odpadów = DE Mülltrennung = RU сортировка мусора. CZ "classifying waste", PL "segregating waste", DE "trash-separating", RU "sorting trash."
