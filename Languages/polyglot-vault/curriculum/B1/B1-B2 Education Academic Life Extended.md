> **Exam:** CZ zkouška = PL egzamin = DE Prüfung = RU экзамен. CZ uses native word, others use Latin.
> **To pass:** CZ složit (zkoušku) = PL zdać (egzamin) = RU сдать (экзамен) — different verbs! CZ "fold/put together", PL "manage", RU "hand in/deliver".
> **To fail:** CZ propadnout = PL oblać/nie zdać = RU провалиться. CZ "fall through", PL "pour over/not manage", RU "fall through" — CZ+RU same metaphor!
> **School-leaving exam:** CZ maturita = PL matura = DE Abitur = RU аттестат зрелости. CZ+PL use "maturita/matura" (from Latin "maturus"=mature). DE has its own word. RU uses "certificate of maturity."
> **Self-taught:** CZ samouk = RU самоучка — cognate! "samo-uk" = "self-learner." PL samouk is the same word.
