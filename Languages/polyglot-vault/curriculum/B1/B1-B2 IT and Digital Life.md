> **Password:** CZ heslo = PL hasło — cognate! Both from "heslo" (slogan/watchword). DE Passwort, RU пароль, EN password all from French "parole".
> **Error/bug:** CZ chyba = PL błąd — different words. But CZ "chyba" in PL means "probably"! ⚠️ False friend context.
> **Library (programming):** CZ knihovna = PL biblioteka = RU библиотека = DE Bibliothek — same word used for both code libraries and book libraries.
> **Download/Upload:** CZ stáhnout/nahrát = PL ściągnąć/wgrać — different verbs but same prefix logic (down/up).
